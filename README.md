# SGS 단가산출 → 수공폼 변환 도우미

`excel_page_formatter.py` 는 실행 중인 Excel 2010/2016 인스턴스에 붙어서 특정
워크시트의 페이지 구성을 자동으로 정리해 주는 도구입니다. 특히
`"산근 n 호표"` 형식의 머리글을 감지하여 페이지 나누기를 다시 만들고 각
페이지의 마지막 인쇄 행에만 가로선을 넣어 주도록 설계되었습니다.

## 주요 기능

* ActiveWorkbook 의 시트 목록을 드롭다운으로 제공하여 원하는 시트를 선택
  후 바로 처리할 수 있습니다.
* 용지 방향/크기, 여백, 반복 행, 배율/맞춤 모드, 인쇄 영역 범위 등을 UI에서
  손쉽게 설정합니다.
* 정규식으로 정의된 머리글 패턴(기본: `^산근\s+\d+\s*호표`)을 찾아 섹션별로
  수평 페이지 나누기를 삽입합니다.
* 사용자가 지정한 열 범위(A~J 등)와 여유 행 수만큼 PrintArea 를 확장한 뒤
  각 페이지 맨 아래 행에만 아래 테두리를 적용합니다.
* 완전히 빈 페이지의 하단선 생략, 기존 페이지 나누기 초기화 여부 등을 옵션으로
  제어할 수 있으므로 다른 섹션(공정별, 공종별 등)에도 재활용할 수 있습니다.

## 실행 방법

1. **Windows** 환경에서 Excel(2010/2016)을 실행하고 대상 파일을 연 뒤,
   해당 파일이 ActiveWorkbook 인 상태를 유지합니다.
2. Python 3과 pywin32(win32com) 모듈이 설치되어 있어야 합니다. PowerShell이나 CMD에서
   아래 명령으로 설치 여부를 확인/설치할 수 있습니다.

   ```powershell
   python -m pip install --upgrade pywin32
   ```

3. 준비가 되면 아래와 같이 스크립트를 실행합니다.

   ```bash
   python excel_page_formatter.py
   ```

4. 나타나는 GUI에서 시트와 옵션을 선택한 뒤 `실행` 버튼을 누르면 선택한 시트에만
   페이지 분할 및 하단선 적용 로직이 수행됩니다.

> **참고:** 이 스크립트는 Excel COM 객체에 의존하므로 Windows 외 환경에서는 동작하지
> 않습니다. (코드는 다른 플랫폼에서도 열람/수정할 수 있지만 실행은 불가합니다.)
