# 단가산출 & 일위대가 페이지 도우미 재설계안

이 문서는 기존 Python 구현을 전면 폐기하고, 두 종류의 Excel 자동화 도구를 다시
작성하기 위한 요구사항과 로직을 정리한 것입니다. 실제 코드는 모두 삭제했으며,
아래 설계를 바탕으로 새 모듈을 재작성해야 합니다.

## 1. 공통 실행/GUI 흐름

1. **Excel 인스턴스 연결**
   * 실행 중인 Excel(2010/2016) 프로세스를 찾아 ActiveWorkbook 을 확보한다.
   * ActiveWorkbook 이 없거나 Excel 이 실행되지 않았으면 명확한 오류 메시지를 표시한다.

2. **워크시트 선택 UI**
   * 드롭다운: Workbook 의 Worksheets 이름 목록을 나열, 기본값은 ActiveSheet.
   * 체크박스(추후 확장): 현재 시트만 처리 / 복수 시트 처리.

3. **페이지 설정 섹션**
   * 용지 방향: 가로/세로 라디오 버튼, 기본은 가로.
   * 용지 크기: A4, B4, 사용자 지정.
   * 여백(mm 또는 inch): 상/하/좌/우 + 머리글/바닥글 여백 입력.
   * 확대/축소: "가로 1 페이지, 세로 자동" 고정. Fit Tall, Zoom 입력은 숨긴다.
   * 반복 행: 시작/끝 행 입력(기본 1~4). PageSetup.RowsToRepeatAtTop 또는 PrintTitleRows 로 설정.

4. **테두리/인쇄 범위 섹션**
   * 시작 열 / 끝 열: 문자 입력(A, DA 등). 기본은 A ~ DA.
   * 추가 행: UsedRange 마지막 행 아래로 얼마나 PrintArea 를 확장할지 지정, 기본 3.
   * 기존 수동 페이지 나눔 초기화 여부 토글.
   * 완전 빈 페이지 하단선 생략 여부(단가산출 전용).

5. **실행/취소 버튼**
   * "실행" 클릭 시 선택한 시트에 대해 아래 로직을 수행하고 요약 메시지를 보여준다.

## 2. 단가산출(산근) 포맷터 재작성 로직

1. **대상 시트**: 사용자가 선택한 워크시트. 기본 패턴은 `^산근\s+\d+\s*호표`.
2. **기본 정보 수집**
   * UsedRange 기반 마지막 행, 반복 행 범위, 시작/끝 열, 추가 행 → PrintArea 계산.
   * `PrintArea = (첫 행, 시작 열) ~ (UsedRange 마지막 행 + 추가 행, 끝 열)`.
3. **페이지 나눔 준비**
   * 옵션이 켜져 있으면 `ResetAllPageBreaks()` 후 다시 계산.
   * 머리글 열(기본 A)에서 정규식 패턴을 찾아 header_rows 목록을 만든다.
4. **페이지 분할**
   * header_rows 가 2개 이상이면 두 번째 이후 머리글 앞에 `HPageBreaks.Add` 로 수동 나눔선을 삽입.
   * Excel 자동 나눔선도 포함해 `page_ranges` 를 계산: `[start_row, end_row]` 리스트.
5. **페이지 길이 보정(옵션)**
   * 반복 행을 제외한 본문 행 수 기준으로 가장 긴 페이지를 찾아 baseline 으로 사용.
   * 페이지가 baseline 보다 짧으면, 해당 페이지의 마지막 데이터 행부터 위로 거슬러 올라가며
     Excel 행 높이 상한(약 409pt)을 넘지 않는 범위에서 행 높이를 늘려 준다.
   * 늘린 행의 텍스트 정렬은 위쪽으로 맞춰 어색함을 줄인다. 필요하면 추가 빈 행을 활용.
6. **테두리 처리**
   * 반복 행 범위는 보호한다.
   * 기존 전폭 가로선은 반복 행을 제외하고 모두 삭제.
   * 페이지 끝 행마다 `first_col~last_col` 범위의 아래 테두리를 Thin 으로 설정.
   * 머리글이 길어 자동 페이지가 생기는 경우에도 동일하게 적용.
7. **보고**
   * 처리한 페이지 수, 늘린 행 수, 새로 그린 하단선 개수 등을 메시지로 출력.

## 3. 일위대가 테두리 도우미 재작성 로직

1. **대상 시트**: 기본 시트명 `일위대가`. 머리글 패턴은 `^제\s+\d+\s*호표`.
2. **호표 구간 식별**
   * 머리글 셀을 위에서 아래로 탐색하여 `[(시작 행, 종료 행)]` 구간 리스트를 만든다.
   * 종료 행은 다음 머리글의 바로 위 행, 마지막 머리글은 시트의 마지막 데이터 행까지.
3. **페이지 정렬 전략**
   * Excel 자동 페이지 나눔 결과를 먼저 읽어 `page_ranges` 를 만든다.
   * 각 호표 구간이 `page_ranges` 중 하나를 넘길 경우, 해당 호표 시작 전에 빈 행을 삽입해 다음 페이지로 넘긴다.
   * 빈 행 삽입 시 `CopyOrigin=xlFormatFromLeftOrAbove` 로 기존 스타일을 물려받게 한다.
4. **페이지 나눔 고정**
   * 삽입 이후에도 자동 나눔이 꼬일 수 있으므로, 계산된 페이지 시작 행 앞에 수동 `HPageBreak` 를 넣어 준다.
   * 단, 한 호표가 한 페이지를 넘어갈 정도로 길다면 중간에 수동 나눔선을 추가해 강제로 다음 페이지로 넘긴다.
5. **테두리 정책**
   * 반복 행(예: 1~4행)은 어떤 테두리 재도색에서도 제외.
   * 시트에 이미 존재하는 얇은 세로 격자는 그대로 둔다.
   * 페이지 경계: 시작 열 왼쪽, 끝 열 오른쪽, 페이지 상단/하단에 Thin 굵기의 테두리를 그린다.
   * 머리글 행의 상단에도 Thin 선을 덧칠해 페이지가 넘어갈 때 끊기지 않도록 한다.
6. **페이지 경계용 빈칸**
   * 각 페이지 나눔선 바로 위 행을 "더미"로 사용: 하단/좌우/세로선을 제거하고 상단에만 Thin 선을 남겨 빈 칸처럼 보이게 한다.
   * 빈 칸 처리 시 반복 행이나 실제 머리글 행을 손상시키지 않도록 범위를 조정한다.
   * 다음 페이지 첫 행의 상단에도 Thin 선을 다시 그려 출력에서 끊김이 없게 한다.
7. **보고 항목**
   * 삽입한 빈 행 개수, 수동 페이지 나눔선 개수, 빈 칸으로 전환된 행 목록 등.

## 4. 향후 구현 체크리스트

* **의존성 안내**: README 맨 위에 Windows + Excel + pywin32 전용임을 강조.
* **오류 처리**: Excel 연결 실패, Workbook 미존재, 잘못된 열 문자 입력 등 사용자가 바로 이해할 수 있는 메시지 필요.
* **로그/요약 UI**: 실행 결과를 GUI 텍스트 박스나 팝업으로 제공.
* **코드 구조**: COM 인터페이스 처리를 모듈화하여 두 도구가 공통 유틸(예: ExcelSession, PageSetupOptions 등)을 공유하도록 설계.
* **테스트 전략**: pywin32 를 통한 단위 테스트는 제한적이므로, 주요 함수는 가능한 범위에서 순수 Python 로직(예: 정규식 파싱, 페이지 계산)으로 분리해 테스트한다.

이 설계를 토대로 다시 구현을 진행하면, 기존 혼재된 로직 대신 목적별로 명확히 분리된 두 개의 모듈을 안정적으로 작성할 수 있다.
